# netwrok-traffic-foundations
This repo demonstrates how I trace traffic from source to destination and map it to logs and alerts.

Networking is the complete process of identifying devices, establishing communication, transmitting structured data, and controlling how that data flows securely across networks.

This repository demonstrates my ability to trace network traffic from source to destination and explain what is happening at each stage using real packet captures, system commands, and protocol-level analysis.
Every concept here is validated using actual traffic observed through Wireshark and Linux tools.
