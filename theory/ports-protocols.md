# TCP VS UDP 
core difference -

TRANSIMISSION CONTROL PROTOCOL (TCP)-

-Its reliable,connection-based

-Used when data must arrive correctly 

USER DATAGRAM PROTOCOL(UDP)

-Fast , connectionless

-Used when speed matters more than accuracy 

TCP IS USED FOR-

Websites(HTTP/HTTPS)

Login systems

File transfers


UDP IS USED FOR-

streaming

dns queires
